<Callout type="warn">
  eTracker tracks in cookie-less mode by default without requiring consent (GDPR
  compliant). This integration enables cookies only when users consent,
  providing enhanced tracking. Do not block the eTracker script itself.
</Callout>

## Prerequisites

Before starting, you'll need:

- Your eTracker account key (also called "secure code")
- Your website domain name

<Callout type="info">
  Find your account key in your eTracker dashboard under Integration → Tracking
  Code, or in Account → Account Key. It's an alphanumeric string like "ABC123".
</Callout>

## Integrate eTracker with Consenter

<Callout type="warn">
  **Important**: Before using this code, verify that the service ID and purpose
  ID values are up to date. These IDs are specific to your Consenter
  configuration. To find the correct IDs, go to [Consenter
  Manager](https://manager.consenter.eu) → Your Site → Active Banner → Hover
  over the service and purpose labels and click the copy button in the tooltip.
  See the [Integration Guides](/integration-guides) page for detailed
  instructions.
</Callout>

Copy the code below and paste it into your website's `<head>` section.
Replace the placeholders with your own values:

- `YOUR_SERVICE_ID` → Your eTracker service ID from Consenter Manager
- `YOUR_PURPOSE_ID` → Your purpose ID from Consenter Manager
- `YOUR_ACCOUNT_KEY` → Your eTracker account key
- `yourdomain.com` → Your website domain (e.g., example.com)

```html title="index.html" lineNumbers
<script id="_etLoader" type="text/javascript" charset="UTF-8"
        data-block-cookies="true"
        data-secure-code="YOUR_ACCOUNT_KEY" // [!code highlight]
        src="//code.etracker.com/code/e.js" async>
</script>

<script>
  var _etrackerOnReady = typeof _etrackerOnReady === 'undefined' ? [] : _etrackerOnReady;
  var serviceId = "YOUR_SERVICE_ID"; // Replace with your service ID from Consenter Manager [!code highlight]
  var purposeId = "YOUR_PURPOSE_ID"; // Replace with your purpose ID from Consenter Manager [!code highlight]

  function subscribeToConsenter() {
    window.consenter.subscribe(
      function (hasConsent) {
        if (hasConsent) {
          _etrackerOnReady.push(function() {
            _etracker.enableCookies('yourdomain.com'); // [!code highlight]
          });
        } else {
          _etrackerOnReady.push(function() {
            _etracker.disableCookies('yourdomain.com'); // [!code highlight]
          });
        }
      },
      serviceId, // [!code highlight]
      purposeId // [!code highlight]
    );
  }

  if (window.consenter) {
    subscribeToConsenter();
  } else {
    document.addEventListener("consenter:ready", subscribeToConsenter);
  }
</script>
```

eTracker is now connected to Consenter.
