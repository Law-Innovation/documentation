<summary>Begründung &amp; Quellen</summary>

**Key Facts:**
BIDSWITCH is an ad-exchange matching service (Improve Digital/Equativ group) that synchronises cookie IDs and audience data across multiple DSPs and SSPs for programmatic advertising. This constitutes both cross-publisher audience aggregation (RF1) and sharing for others' own advertising purposes (RF3). EU-based (Improve Digital International, Amsterdam) is a mitigating factor.

**Quellen:**
