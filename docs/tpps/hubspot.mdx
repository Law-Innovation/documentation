<summary>Reasoning &amp; Sources</summary>

**Key Facts:**
HubSpot's tracking code (HubSpot Tracking Code / Beacon) collects visitor IP addresses, online identifiers, and behavioural data. HubSpot's own Privacy Policy explicitly states this data may be used for 'Breeze Intelligence' (HubSpot's commercial B2B intent data product) — a form of own-purpose data use beyond pure processing (A=1). This is not enabled by default for all accounts but is disclosed as a product feature. Controllers can opt out of intent-data sharing. US company; DPF and SCCs. Robust DPA publicly available. Comprehensive GDPR features (consent tracking, deletion tools, data subject rights). No advertising profiling of visitors for HubSpot's own advertising.
