<summary>Begründung &amp; Quellen</summary>

**Key Facts:**
Retency Web Audience (Retency SAS, Paris) is included in CNIL's official consent-exemption list and CNIL published a dedicated configuration guide. Technical design ensures consent-free compliance: IP truncated to city level (last octet removed); first-party cookies scoped to single domain (no cross-site tracking); only aggregated statistics produced (no individual-level records); no external data import; no user profiling for targeting. Retency acts strictly as processor (sous-traitant); data never used for Retency's own purposes. DPA provided with subscription. EU/France hosting.

**Quellen:**
