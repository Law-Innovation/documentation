<summary>Reasoning &amp; Sources</summary>

**Key Facts:**
AddToAny social sharing buttons load US-hosted scripts and set cookies tracking which content a user shares and to which platforms, across all AddToAny-enabled sites. US company. No formal advertising profile-building in the classic sense, but cross-site data collection for AddToAny's own analytics is inherent to the product.

**Framework Note (v2.2):**
FRAMEWORK NOTE: Under the revised framework (v2.1), default-on tracking that is fully resolvable by a CMP is treated as normal. AddToAny's Caution badge is maintained because the own-purpose cross-site data collection is STRUCTURAL — it is not resolved by a consent banner on the embedding website, as AddToAny continues to collect sharing data across its network regardless of the individual site's CMP configuration.
