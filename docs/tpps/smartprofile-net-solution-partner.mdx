<summary>Reasoning &amp; Sources</summary>

**Key Facts:**
SmartProfile (Net Solution Partner SAS, Nice, France) is a web analytics and marketing automation platform. The analytics module obtained CNIL consent exemption, confirmed in CNIL's published list of compliant analytics tools. Operates strictly as a processor (sous-traitant) for customers; no data used for NSP's own commercial purposes. IP addresses and identifiers anonymised; cross-site tracking disabled by design; scoped exclusively to the controller's own site. On-premise deployment option available. DPA concluded contractually. EU/France hosting. No international transfers for standard deployment.
