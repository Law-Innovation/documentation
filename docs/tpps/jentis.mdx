<summary>Begründung &amp; Quellen</summary>

**Key Facts:**
JENTIS (Vienna, Austria) is a server-side tag management and data capture platform. ISO 27001 certified. All infrastructure is EU-based (Austria/Germany). Business model is B2B SaaS processor only — no own-purpose advertising, profiling, or data brokering. JENTIS's architecture captures first-party data server-side on behalf of the controller, keeping the controller as sole data controller while enabling pseudonymised/anonymised routing to downstream tools — directly addressing the Schrems II third-party transfer problem. 'Essential Mode' enables consent-free data capture for analytics. Built-in pseudonymisation and anonymisation. Comprehensive DPA; detailed sub-processor disclosure.
