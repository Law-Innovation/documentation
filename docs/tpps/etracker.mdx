**Key Facts:**
etracker Analytics operates exclusively from servers in Hamburg, Germany. In its default cookieless configuration, no persistent identifiers are set, IP addresses are truncated server-side immediately on receipt, and no data is processed for etracker's own purposes. ePrivacy GmbH independently certified that etracker's cookieless mode requires no user consent under German TDDDG and GDPR. The CNIL confirmed a compatible configuration for French deployments. etracker acts strictly as a processor for all customer data, with no advertising or data-sharing model. DPA is automatically concluded at account creation. ISO 27001 orientation. No international transfers.
