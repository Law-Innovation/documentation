<details>
<summary>Begründung &amp; Quellen</summary>

**Key Facts:**
eStat-Streaming is operated by Médiamétrie (the French broadcast/streaming audience measurement authority). CNIL published a dedicated configuration guide confirming consent-exempt status. Technical design is exceptionally privacy-protective: IP address is read only for country-level geolocation then hashed using murmur3 with a per-site, per-month rotating key (key not retained after expiry — making historical IP reconstruction technically impossible); no third-party cookies; no UID/IDFA/ADID transmitted in exempt mode; campaign measurement disabled by default; data aggregated only. Médiamétrie acts strictly as processor for each subscribing publisher; no data used for Médiamétrie's own purposes. DPA annexed to subscription contract. France-based; EU hosting.
