<summary>Begründung &amp; Quellen</summary>

**Key Facts:**
Abla Analytics (Astra Porta, Marseille, France) obtained formal CNIL consent exemption confirmation. CNIL published a dedicated configuration guide for Abla Analytics on cnil.fr, confirming exempt status — the highest available public-authority validation for a French analytics tool. IP addresses are anonymised instantly on receipt; no persistent identifiers link visits across sites; no cross-site tracking; three available tiers (Analytics, Analytics+, Analytics x) are all compliant in default configuration. Operates as processor (sous-traitant). French/EU hosting. DPA included contractually.
