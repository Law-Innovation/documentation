Typical processing purposes: Improve the service

<Callout type="info" title="Overview">
This guide explains how to reflect the New Relic browser agent (real user monitoring) in the Consenter Manager. Server-side APM is out of scope. The current agent offers no visitor-facing privacy switches beyond those noted, so this guide uses a single fixed-behaviour table.

1. Implement the service as described below.
2. Map the implementation in the Consenter Manager.
3. Update your privacy policy to reflect the actual implementation.

The mapping is an example, not a guarantee of legal compliance. Verify it against your implementation and current provider documentation.
</Callout>

## At a glance

**Scope.** New Relic browser agent v1220 and later.

**What the service does in this scope.** For agent v1220 and later, the session cookies (`JSESSIONID`, `NREUM`) are deprecated. New Relic briefly collects the end user's IP address to look up country, region, city and ASN details, and no longer retains it once mapping is complete (typically minutes, up to 24 hours). New Relic notes that a consent manager with a conditional script loader can load the agent only after consent.

> ⚠ **Recommendation.** Check the agent version and any session features you enable (such as session replay or traces) in your browser app settings, and inspect browser storage before finalising this mapping.

## Step 1 — Implement New Relic Browser

| Configuration area | Fixed behaviour / required action |
|---|---|
| Processing purposes | Improve the service (performance monitoring) |
| Agent version | v1220 or later |
| Loading | After Consenter consent via conditional loading |
| Contract | New Relic DPA |

## Step 2 — Map the configuration in the Consenter Manager

| Consenter Manager field | Value to select | Basis and conditions |
|---|---|---|
| Processing purposes | Improve the service | — |
| Tracking method | First party tracking (single session) | Verify session features in use |
| Identifier | IP address | Briefly, for geo lookup |
| Data categories | Aggregated site statistics, Device characteristics, Browsing and interaction data, Non-precise location data, IP address | — |
| Legal role of data recipient | Processor | New Relic DPA |
| Personalisation model | No personalisation | — |
| Maximum storage duration | IP: up to 24 hours; other data per retention settings | — |
| Processing location | United States / EU region per account | US enterprise; CLOUD Act|
