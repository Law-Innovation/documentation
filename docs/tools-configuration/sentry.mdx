<Callout type="info" title="Overview">
This guide explains how to implement different privacy configurations for the Sentry browser SDK (error monitoring and Session Replay) and how to reflect them in the Consenter Manager.

1. Configure the third-party service.
2. Map the selected configuration in the Consenter Manager.
3. Update your privacy policy to reflect the actual implementation.

The configurations are comparative examples, not guarantees of legal compliance. Verify that the guide matches your product edition, implementation, and current provider documentation.
</Callout>

## At a glance

**Scope.** Sentry JavaScript browser SDK.

**What the service does in this scope.** Session Replay records user sessions; by default it masks all text with `*` and blocks media elements on the client before sending. `maskAllText`, `maskAllInputs` and `blockAllMedia` default to `true`. Disabling masking is only intended for sites with no sensitive data.

**Configurations included.**

| Configuration | Summary |
|---|---|
| Configuration A — Lower risk | Error monitoring only; no Session Replay. |
| Configuration B — Medium risk | Session Replay with default masking and blocking, after Consenter consent. |
| Configuration C — Higher risk | Session Replay with `maskAllText: false` / `blockAllMedia: false`, after consent. |

> ⚠ **Recommendation.** Whether error monitoring in A can run without consent depends on what data your events carry. Have your DPO confirm the legal basis before running A without a consent entry.

## Step 1 — Configure Sentry

| # | Configuration area | Where to configure it | Configuration A — Lower risk | Configuration B — Medium risk | Configuration C — Higher risk |
|---|---|---|---|---|---|
| 1 | Processing purposes | Operator decision | Improve the service | Improve the service | Improve the service |
| 2 | Session Replay | `Sentry.replayIntegration` | Not added | Added | Added |
| 3 | Masking | `maskAllText`, `maskAllInputs`, `blockAllMedia` | — | Defaults (`true`) | `maskAllText: false`, `blockAllMedia: false` |
| 4 | Loading | Front-end | Per DPO assessment | After Consenter consent | After Consenter consent |
