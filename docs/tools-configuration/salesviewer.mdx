## At a glance

**Scope.** SalesViewer® B2B company identification script on a website. Sources were checked on 16 November 2026.

**What the service does in this scope.** SalesViewer states that its entire tracking works without cookies, that data is collected and stored "without a reference to IP addresses", and that it offers a voluntary opt-out for company-based tracking [S1]. It identifies companies visiting the site (B2B lead generation) [S1].

**Simplified format.** SalesViewer documents no alternative privacy settings. The guide uses a single fixed-behaviour configuration.

> ⚠ **Recommendation — running SalesViewer before consent is legally uncertain.** SalesViewer positions its cookieless technology as usable without consent [S1]. The script still runs in the browser and the IP address is processed transiently to identify the company. Have your DPO or independent counsel confirm before loading SalesViewer without consent; otherwise load it after consent.

## Step 1 — Configure SalesViewer

| Configuration area | Fixed behaviour / required action |
|---|---|
| Processing purposes | Support marketing analytics; Receive marketing offers (if identified companies are approached) |
| Cookies | None for tracking [S1] |
| IP addresses | Not stored with the collected data [S1] |
| Opt-out | Provide SalesViewer's opt-out link (sets an opt-out cookie) |
| Loading | See ⚠ recommendation |
| Retention | **Not documented** — check the DPA |

## Step 2 — Map the configuration in the Consenter Manager

| Consenter Manager field | Value to select | Basis and conditions |
|---|---|---|
| Processing purposes | Support marketing analytics, Receive marketing offers | B2B lead generation [S1]. |
| Tracking method | No tracking | Cookieless [S1]. |
| Identifier | IP address | Processed transiently for company identification. |
| Data categories | IP address, Browsing and interaction data, Device characteristics | Activity data of company visitors. |
| Legal role of data recipient | Processor | Verify against your SalesViewer DPA. |
| Personalisation model | Group based (properties) | Company-level segmentation. |
| Maximum storage duration | Not documented | — |
| Processing location | Per contract | SalesViewer is a German company; check sub-processors. |
