## At a glance

**Scope.** The Nonli analytics SDK served from a custom domain delegated by the publisher. Nonli is a French company.

**What the service does in this scope.** Nonli works only in exempt mode; no specific configuration is required. It sets the cookie `nli` with a unique identifier for 13 months, not extended while the user keeps browsing, and `nli_consent` to record an opt-out, which disables tracking completely. The last octet of the IP address is removed before processing, and location is stored at city level at most. Data is not consolidated across domains, and each brand's cookies carry different identifiers. Nonli acts as processor (sous-traitant).

**Simplified format.** Nonli has a single mode. The guide uses one fixed-behaviour configuration.

> ⚠ **Recommendation — exemption is self-assessed and France-specific.** CNIL treats audience-measurement cookies as exempt from consent only where they serve solely the publisher's audience measurement, produce anonymous statistics, are not cross-referenced or passed on, and do not allow tracking across sites; it recommends a cookie lifetime of about 13 months without automatic extension and data retention of at most 25 months. CNIL now offers a self-evaluation tool rather than an approval programme, so describe the configuration as a **self-assessed exemption**, not as "CNIL-approved". § 25 TDDDG in Germany contains no equivalent audience-measurement exemption. Run Nonli without consent only after review by your DPO or independent counsel.

## Step 1 — Configure Nonli

| Configuration area | Fixed behaviour / required action |
|---|---|
| Processing purposes | Improve the service (audience measurement) |
| Custom domain | Delegate a subdomain (CNAME) or root domain (A record) and create the custom domain in the Nonli account |
| SDK | Generated per brand; place before `</body>` |
| Cookies | `nli` (13 months, not extended), `nli_consent` (opt-out) |
| IP handling | Last octet removed before processing |
| Opt-out | Link to `https://<custom-domain>/cookie/consent` or embed the opt-out button |
| Loading | See ⚠ recommendation |

## Step 2 — Map the configuration in the Consenter Manager

| Consenter Manager field | Value to select | Basis and conditions |
|---|---|---|
| Processing purposes | Improve the service | Audience measurement only. |
| Tracking method | First party tracking (cross-session) | `nli`, 13 months. |
| Identifier | Device identifiers | Unique identifier in `nli`. |
| Data categories | Aggregated site statistics, Browsing and interaction data, Device identifiers, IP address anonymised, Non-precise location data | — |
| Legal role of data recipient | Processor | — |
| Personalisation model | No personalisation | — |
| Maximum storage duration | 13 months (cookie) | Data retention not stated; CNIL recommends at most 25 months. |
| Processing location | Not documented | Request hosting information; Nonli is a French company. |
