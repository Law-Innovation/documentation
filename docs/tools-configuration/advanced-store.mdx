Typical processing purposes: Customise online ads, Receive personalised marketing offers

<Callout type="info" title="Overview">
This guide explains how to reflect advanced store retargeting on an advertiser website in the Consenter Manager. advanced store documents no separate configuration tiers, so this guide uses a single fixed-behaviour table.

1. Implement the service as described below.
2. Map the implementation in the Consenter Manager.
3. Update your privacy policy to reflect the actual implementation.

The mapping is an example, not a guarantee of legal compliance. Verify it against your implementation and current provider documentation.
</Callout>

## At a glance

**Scope.** advanced store retargeting and tracking pixels on advertiser websites. Sources were checked on 16 November 2026.

**What the service does in this scope.** advanced store GmbH (Berlin) offers an opt-out [S1].

> **Note on consent signals.** advanced store works with the IAB TCF consent signal [S1]. Consenter does not currently support TCF communication, so this guide does not cover configuring the signal; load the pixel only after consent in Consenter. Tracking pixels integrated on pages establish a direct connection between the visitor's browser and advanced store or a third party [S2]. advanced store publishes a list of cooperation partners and subcontractors [S1][S2].

> ⚠ **Research gap.** advanced store does not publish cookie names, durations or its GDPR role toward advertisers in the sources found. Confirm these in your contract before finalising the mapping.

## Step 1 — Implement advanced store

| Configuration area | Fixed behaviour / required action |
|---|---|
| Processing purposes | Customise online ads; Receive personalised marketing offers (retargeting) |
| Loading | Load the pixel only after Consenter consent |
| Contract | advanced store partner terms; partner list [S1] |

## Step 2 — Map the configuration in the Consenter Manager

| Consenter Manager field | Value to select | Basis and conditions |
|---|---|---|
| Processing purposes | Customise online ads, Receive personalised marketing offers | Retargeting |
| Tracking method | Third party tracking (crosssession, cross-website) | Tracking pixels [S2] |
| Identifier | Device identifiers | Cookie IDs |
| Data categories | Device identifiers, Browsing and interaction data, e-commerce Activity, Users' profiles | Retargeting |
| Legal role of data recipient | Individual Controller | Verify in contract (⚠) |
| Personalisation model | Profile based | Retargeting |
| Maximum storage duration | Per advanced store privacy policy [S3] | — |
| Processing location | Germany / EU; partners per subcontractor list | Check partner list for US recipients; CLOUD Act [S4] |
