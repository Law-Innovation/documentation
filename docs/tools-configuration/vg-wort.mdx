## At a glance

**Scope.** VG Wort counting pixels (Zählmarken) embedded in texts via the METIS system so that authors and publishers can claim statutory remuneration. Verwertungsgesellschaft Wort is a German collecting society. Sources were checked on 16 November 2026.

**What the service does in this scope.** Each text carries a counting pixel that reports page accesses to the VG Wort counting server [S1]. Access counting recognises systems either by a **session cookie** with a random session ID or by a signature formed from information the browser transmits automatically [S2]. VG Wort's position, as reported, is that counting is anonymous and the cookie only serves to prevent incorrect counts and fraud [S3].

**Simplified format.** VG Wort documents no privacy options for publishers. The guide uses a single fixed-behaviour configuration.

> ⚠ **Recommendation — consent status is disputed.** Commentators argue that the session cookie is not technically necessary and therefore needs consent under § 25 TDDDG [S4]; others treat counting for statutory remuneration as necessary [S5]. The alternative signature method reads browser information and raises the same question. Load the pixel after consent unless your DPO or independent counsel confirms an exemption; note that without counting, remuneration claims may be lost.

## Step 1 — Configure VG Wort

| Configuration area | Fixed behaviour / required action |
|---|---|
| Processing purposes | Unlock additional website features (statutory remuneration counting) |
| Pixel placement | Per METIS documentation, one pixel per text [S1] |
| Recognition method | Session cookie or browser signature [S2] |
| Loading | See ⚠ recommendation |
| Retention | **Not documented** |

## Step 2 — Map the configuration in the Consenter Manager

| Consenter Manager field | Value to select | Basis and conditions |
|---|---|---|
| Processing purposes | Unlock additional website features | Closest available purpose; the processing serves statutory author remuneration. Taxonomy gap: no purpose describes rights-management counting. |
| Tracking method | First party tracking (single session) | Session cookie or signature for the current session [S2]. |
| Identifier | Device identifiers, Probabilistic identifiers | Session ID or browser signature [S2]. |
| Data categories | IP address, Device characteristics, Browsing and interaction data, Probabilistic identifiers | Pixel request data [S2]. |
| Legal role of data recipient | Individual Controller | VG Wort counts for its own statutory distribution purposes. |
| Personalisation model | No personalisation | — |
| Maximum storage duration | Session (cookie) | [S2] |
| Processing location | Germany | VG Wort, Munich. |
