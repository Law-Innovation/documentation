Typical processing purposes: Improve the service

<Callout type="info" title="Overview">
This guide explains how to reflect Cloudflare Web Analytics in the Consenter Manager. Cloudflare's CDN, DNS, WAF and bot-management functions are strictly necessary infrastructure and are out of scope. Web Analytics has no visitor-facing privacy settings, so this guide uses a single fixed-behaviour table.

1. Implement the service as described below.
2. Map the implementation in the Consenter Manager.
3. Update your privacy policy to reflect the actual implementation.

The mapping is an example, not a guarantee of legal compliance. Verify it against your implementation and current provider documentation.
</Callout>

## At a glance

**Scope.** Cloudflare Web Analytics, collected via the JavaScript beacon or at Cloudflare's edge.

**What the service does in this scope.** Web Analytics does not use client-side state such as cookies or localStorage to collect usage metrics, and Cloudflare states it does not fingerprint individuals via IP address or user agent for analytics. It counts "visits" based on referrer rather than unique visitors.

> ⚠ **Recommendation.** No device storage is used, but the beacon is still loaded from Cloudflare and page-view data is transmitted to a US company. If you load it without consent, treat this as a self-assessed exemption and have your DPO confirm the legal basis (GDPR) separately from the device-access question (§ 25 TDDDG). Otherwise load it after Consenter consent.

## Step 1 — Implement Cloudflare Web Analytics

| Configuration area | Fixed behaviour / required action |
|---|---|
| Processing purposes | Improve the service |
| Collection | JavaScript beacon or edge collection |
| Loading | After Consenter consent, or without consent per the ⚠ note |
| Contract | Cloudflare DPA |

## Step 2 — Map the configuration in the Consenter Manager

| Consenter Manager field | Value to select | Basis and conditions |
|---|---|---|
| Processing purposes | Improve the service | — |
| Tracking method | No tracking | No client-side state |
| Identifier | No identifier | No fingerprinting |
| Data categories | Aggregated site statistics, Device characteristics | Page views, referrers, performance |
| Legal role of data recipient | Processor | Cloudflare DPA |
| Personalisation model | No personalisation | — |
| Maximum storage duration | Per Cloudflare documentation | — |
| Processing location | United States | US enterprise; CLOUD Act|
