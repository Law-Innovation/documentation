The configuration is a comparative example, not a guarantee of legal compliance. Verify that the guide matches your product edition, implementation, and current provider documentation.

## At a glance

**Scope.** Alphalyr Analytics JavaScript tag. Alphalyr is a French company; hosting is with Scaleway.

**What the service does in this scope.** Alphalyr collects a session ID (30-minute sliding lifetime), browser type, device type, referrer, visited page URL and a partial IP address sufficient for city-level location; it does not retrieve URL parameters from referrers. Results are visible only as aggregated statistics per dimension and day. Alphalyr acts as processor and processes no personal data for its own account. The `OPTOUT` parameter (`1`) deletes the session cookie and stops collection.

**Simplified format.** Alphalyr has one measurement mode plus opt-out. The guide uses a single fixed-behaviour configuration.

> ⚠ **Recommendation — exemption is self-assessed and France-specific.** CNIL treats audience-measurement tracers as exempt only under strict conditions. Describe this configuration as a **self-assessed exemption**. § 25 TDDDG in Germany contains no equivalent exemption. Run Alphalyr without consent only after review by your DPO or independent counsel.

## Step 1 — Configure Alphalyr

| Configuration area | Fixed behaviour / required action |
|---|---|
| Processing purposes | Improve the service |
| Tag placement | All pages, before `</head>` |
| Session cookie | 30-minute sliding lifetime |
| IP handling | Partial IP only (city level) |
| Opt-out | `OPTOUT=1` via a form or preference button |
| URLs with personal data | Do not tag such pages |
