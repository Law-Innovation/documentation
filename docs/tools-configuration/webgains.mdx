Typical processing purposes: Support marketing analytics

<Callout type="info" title="Overview">
This guide explains how to reflect Webgains affiliate tracking on an advertiser website in the Consenter Manager. Webgains' tracking runs in a single consent-gated mode, so this guide uses a single fixed-behaviour table.

1. Implement the service as described below.
2. Map the implementation in the Consenter Manager.
3. Update your privacy policy to reflect the actual implementation.

The mapping is an example, not a guarantee of legal compliance. Verify it against your implementation and current provider documentation.
</Callout>

## At a glance

**Scope.** Webgains onsite script and conversion tracking. Sources were checked on 16 November 2026.

**What the service does in this scope.** Webgains' default method is a first-party cookie, `_CK_WG_`, set by the onsite script on the advertiser domain when a user arrives via an affiliate link [S1][S2]. The cookie stores campaign, programme ID and a unique click reference; the script only drops it on user consent and no user-identifiable information is sent [S2]. A `consent=1` / `consent=0` parameter can be passed in tracking URLs and scripts [S3]. Webgains positions itself as a data processor [S4].

## Step 1 — Implement Webgains

| Configuration area | Fixed behaviour / required action |
|---|---|
| Processing purposes | Support marketing analytics (affiliate attribution) |
| Cookie | `_CK_WG_` first-party, set only on consent [S2] |
| Consent signal | Pass `consent=1/0` from Consenter [S3] |
| Contract | Webgains DPA |

## Step 2 — Map the configuration in the Consenter Manager

| Consenter Manager field | Value to select | Basis and conditions |
|---|---|---|
| Processing purposes | Support marketing analytics | — |
| Tracking method | First party tracking (cross-session) | `_CK_WG_` on advertiser domain [S2] |
| Identifier | Device identifiers | Click reference [S2] |
| Data categories | Device identifiers, Browsing and interaction data, e-commerce Activity, Privacy choices | Conversion data; consent parameter [S3] |
| Legal role of data recipient | Processor | [S4] |
| Personalisation model | No personalisation | — |
| Maximum storage duration | Per programme cookie period | — |
| Processing location | Per Webgains DPA | Check for US sub-processors; CLOUD Act [S5] |
