Typical processing purposes: Improve the service

<Callout type="info" title="Overview">
This guide explains how to implement different privacy configurations for the BugSnag JavaScript notifier (now SmartBear Insight Hub) and how to reflect them in the Consenter Manager.

1. Configure the third-party service.
2. Map the selected configuration in the Consenter Manager.
3. Update your privacy policy to reflect the actual implementation.

The configurations are comparative examples, not guarantees of legal compliance. Verify that the guide matches your product edition, implementation, and current provider documentation.
</Callout>

## At a glance

**Scope.** BugSnag browser JavaScript error monitoring. Sources were checked on 16 November 2026.

**What the service does in this scope.** By default BugSnag records the user's IP address as the user ID; `collectUserIp` prevents this [S1][S2]. It generates an anonymous device ID, which can be prevented via `generateAnonymousId` [S3]. User agent and locale are also captured and can be modified in a callback [S3].

**Configurations included.**

| Configuration | Summary |
|---|---|
| Configuration A — Lower risk | `collectUserIp: false`, `generateAnonymousId: false`. |
| Configuration B — Higher risk (default behaviour) | IP address and anonymous device ID collected. |

> ⚠ **Recommendation.** Whether error monitoring in A can run without consent is a legal assessment. Have your DPO confirm the legal basis before running A without a consent entry.

## Step 1 — Configure BugSnag

| # | Configuration area | Where to configure it | Configuration A — Lower risk | Configuration B — Higher risk (default behaviour) |
|---|---|---|---|---|
| 1 | Processing purposes | Operator decision | Improve the service | Improve the service |
| 2 | Client IP | `collectUserIp` [S2] | `false` | `true` |
| 3 | Device ID | `generateAnonymousId` [S3] | `false` | `true` |

## Step 2 — Map the configuration in the Consenter Manager

**Processing location.** SmartBear is a US enterprise; list the United States (18 U.S.C. § 2713 [S4]).

| Consenter Manager field | Configuration A — Lower risk | Configuration B — Higher risk (default behaviour) |
|---|---|---|
| Entry needed | Per DPO assessment (⚠) | Yes |
| Processing purposes | Improve the service | Improve the service |
| Tracking method | No tracking | First party tracking (cross-session) |
| Identifier | No identifier | Device identifiers, IP address |
| Data categories | Device characteristics | Device characteristics, Device identifiers, IP address |
| Legal role of data recipient | Processor | Processor |
| Personalisation model | No personalisation | No personalisation |
| Maximum storage duration | Per BugSnag retention | Per BugSnag retention |
| Processing location | United States | United States |
