<Callout type="info" title="Overview">
This guide explains how to implement different privacy configurations for Lead Forensics and how to reflect them in the Consenter Manager.

1. Configure the third-party service.
2. Map the selected configuration in the Consenter Manager.
3. Update your privacy policy to reflect the actual implementation.

The configurations are comparative examples, not guarantees of legal compliance. Verify that the guide matches your product edition, implementation, and current provider documentation.
</Callout>

## At a glance

**Scope.** The Lead Forensics tracking code for reverse business-IP identification.

**What the service does in this scope.** The JavaScript collects non-personal attributes and the IP address and matches business IP addresses to organisations. The **basic code** does not drop a cookie; the optional **advanced code** sets the `lfuuid` cookie (a random GUID) to improve match rates and "should be placed behind a consent banner". Lead Forensics acts as data processor under a DPA. Data may be processed by group companies including Lead Forensics Limited (UK) and Lead Forensics, Inc. (US).

**Configurations included.**

| Configuration | Summary |
|---|---|
| Configuration A — Medium risk (⚠ no-consent) | Basic code only (no cookie). |
| Configuration B — Higher risk | Advanced code with `lfuuid` cookie, after consent. |

> ⚠ **Recommendation — running the basic code before consent is legally uncertain.** Lead Forensics requires consent only for the advanced (cookie) code. The basic script still runs in the browser and processes the IP address. Have your DPO or independent counsel confirm before loading it without consent.

## Step 1 — Configure Lead Forensics

| # | Configuration area | Where to configure it | Configuration A — Medium risk | Configuration B — Higher risk |
|---|---|---|---|---|
| 1 | Processing purposes | Operator decision | Support marketing analytics; Receive marketing offers | Same |
| 2 | Code version | Lead Forensics portal: basic vs. advanced code | Basic | Advanced |
| 3 | Loading | Consenter script blocking | See ⚠ recommendation | After consent |
| 4 | Contact data feature | Portal feature | Not used | Optional (add "direct identifier") |
| 5 | DPA | Lead Forensics DPA | Concluded | Concluded |
