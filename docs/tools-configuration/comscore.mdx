## At a glance

**Scope.** The Comscore Publisher Web Page Impression Tag for Media Metrix audience measurement (beacon to `sb.scorecardresearch.com`). Comscore, Inc. is a US company.

**What the service does in this scope.** The tag sends page impression data such as page URL, referrer, browser type and cookie values with each call. Consent for audience research is communicated with the `cs_ucfr` label (`1` = consent, `0` = no consent, blank = no action); Comscore requires recipients to have an auditable consent trail. An optional publisher-specific first-party cookie `_scor_uid` is disabled by default; when enabled, it is set only with a consent signal from a CMP or `cs_ucfr=1`, unless the publisher sets `bypassUserConsentRequirementFor1PCookie`.

**Configurations included.**

| Configuration | Summary |
|---|---|
| Configuration A — Higher risk | Publisher tag after consent with `cs_ucfr=1`; first-party cookie disabled (default). |
| Configuration B — Highest risk | As A, plus the first-party `_scor_uid` cookie enabled. |

**No configuration without prior consent.** The tag sends cookie values and is used for cross-publisher audience research. Do not use the consent-bypass setting for EU visitors; block the tag until consent.

## Step 1 — Configure the Comscore tag

| # | Configuration area | Where to configure it | Configuration A — Higher risk | Configuration B — Highest risk |
|---|---|---|---|---|
| 1 | Processing purposes | Operator decision | Support marketing analytics | Support marketing analytics |
| 2 | Consent label | `cs_ucfr` in the tag (`1` after consent) | `1` | `1` |
| 3 | First-party cookie | `enableFirstPartyCookie` | Off (default) | On |
| 4 | Consent bypass | `bypassUserConsentRequirementFor1PCookie` | Not set | Not set |
| 5 | Loading | Consenter script blocking | After consent | After consent |
