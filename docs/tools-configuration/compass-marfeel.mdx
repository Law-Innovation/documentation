<Callout type="info" title="Overview">
This guide explains how to implement different privacy configurations for Marfeel Compass and how to reflect them in the Consenter Manager.

1. Configure the third-party service.
2. Map the selected configuration in the Consenter Manager.
3. Update your privacy policy to reflect the actual implementation.

The configurations are comparative examples, not guarantees of legal compliance. Verify that the guide matches your product edition, implementation, and current provider documentation.
</Callout>

## At a glance

**Scope.** Marfeel Compass editorial analytics on publisher websites. Marfeel is a Spanish company. Sources were checked on 16 November 2026.

**What the service does in this scope.** Marfeel acts as processor for the publisher [S1]. Without consent, Compass sets no audience-measurement cookie and keeps only page-level information; IP addresses are anonymised to the last octet before processing and location is limited to country level; real-time data is aggregated with at least 5 users, hourly for data under 30 days and daily thereafter [S1]. In exempt mode, personalisation APIs, external data imports, user-level exports, individual navigation paths, UTM parameters and the user ID API (`setSiteUserId`) are disabled [S1]. With consent, Compass uses a first-party cookie [S1]. Consent is read from a TCF v2 CMP (vendor ID 943) or set with `compass.setCookies(false)` [S1].

**Configurations included.**

| Configuration | Summary |
|---|---|
| Configuration A — Lower risk (⚠ no-consent) | Exempt mode: no cookie, page-level aggregated data. |
| Configuration B — Higher risk | After consent: first-party cookie, user ID API, personalisation features. |

> ⚠ **Recommendation — exemption is self-assessed and France-specific.** CNIL treats audience-measurement tracers as exempt only under strict conditions [S2]. Describe A as a **self-assessed exemption**. § 25 TDDDG in Germany contains no equivalent exemption. Even without cookies, the script runs on the device; have your DPO or independent counsel review before running A without consent.

## Step 1 — Configure Compass

| # | Configuration area | Where to configure it | Configuration A — Lower risk (⚠ no-consent) | Configuration B — Higher risk |
|---|---|---|---|---|
| 1 | Processing purposes | Operator decision | Improve the service | Improve the service; Personalise the website |
| 2 | Cookie control | `compass.setCookies(false)` until Consenter consent [S1] | Cookies off | Cookies on after consent |
| 3 | User ID API | `setSiteUserId` (only with consent) [S1] | Not used | Optional |
| 4 | Personalisation APIs | Compass settings [S1] | Disabled | Enabled |

## Step 2 — Map the configuration in the Consenter Manager

| Consenter Manager field | Configuration A — Lower risk (⚠ no-consent) | Configuration B — Higher risk |
|---|---|---|
| Processing purposes | Improve the service | Improve the service, Personalise the website |
| Tracking method | No tracking | First party tracking (cross-session) |
| Identifier | No identifier | Device identifiers, Authentication-derived identifiers (if user ID API used) |
| Data categories | Aggregated site statistics, Browsing and interaction data, Device characteristics, IP address anonymised | Aggregated site statistics, Browsing and interaction data, Device characteristics, Device identifiers, IP address anonymised, Users' profiles |
| Legal role of data recipient | Processor | Processor |
| Personalisation model | No personalisation | Group based (behaviour) |
| Maximum storage duration | Not documented | Not documented |
| Processing location | Not documented (see DPA) | Not documented (see DPA) |

## Privacy-policy follow-up

- Marfeel as processor; exempt vs. consent mode; opt-out ("Paramétrez vos choix" or CMP).
