This guide explains how to implement different privacy configurations for Monotype web fonts (Fonts.com, MyFonts, Monotype Fonts) and how to reflect them in the Consenter Manager.

1. Configure the third-party service.
2. Map the selected configuration in the Consenter Manager.

The configurations are comparative examples, not guarantees of legal compliance. Verify that the guide matches your product edition, implementation, and current provider documentation.
</Callout>

## At a glance

**Scope.** Monotype web fonts self-hosted with the Monotype tracking script, or served from Monotype's CDN. Monotype Imaging Holdings Inc. is a US company.

**What the service does in this scope.** Webfont licences count each page load that calls the webfont kit CSS as a pageview. With self-hosted fonts, the Monotype tracking script collects the anonymised project ID, the licensed website URL linked to a customer ID, and the referrer URL; the visitor's IP address is transferred to Monotype's third-party service provider. Monotype does not use cookies for web font tracking. With Monotype's CDN, the kit links to a tracking CSS (`1.css`) that pushes usage data to Monotype for reporting and licensing.

**Configurations included.**

| Configuration | Summary |
|---|---|
| Configuration A — Medium risk | Self-hosted fonts with the mandatory Monotype tracking script/CSS. |
| Configuration B — Medium risk | Fonts served from Monotype's CDN with tracking CSS. |

> ⚠ **Recommendation — pageview tracking before consent.** No cookies are used, but the tracking request transmits the visitor's IP address to a US provider on every page load. The tracking is a licence condition, not a visitor-facing function. Whether it may run without consent (e.g. under Art. 6(1)(f) GDPR) should be decided by your DPO or independent counsel; otherwise use a font licence without pageview tracking.

## Step 1 — Configure Monotype web fonts

| # | Configuration area | Where to configure it | Configuration A — Medium risk | Configuration B — Medium risk |
|---|---|---|---|---|
| 1 | Processing purposes | Operator decision | Unlock additional website features | Unlock additional website features |
