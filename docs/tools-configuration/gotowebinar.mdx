<Callout type="info" title="Overview">
This guide explains how to reflect GoTo Webinar in the Consenter Manager. On the website, GoTo Webinar is reached through a link to its hosted registration page; the sources document no website embed with configurable privacy settings, so this guide uses a single fixed-behaviour table.

1. Implement the service as described below.
2. Map the implementation in the Consenter Manager.
3. Update your privacy policy to reflect the actual implementation.

The mapping is an example, not a guarantee of legal compliance. Verify it against your implementation and current provider documentation.
</Callout>

## At a glance

**Scope.** GoTo Webinar registration and attendance (GoTo, formerly LogMeIn, a US company). Sources were checked on 16 November 2026.

**What the service does in this scope.** GoTo processes customer personal data as a processor under its Data Processing Addendum [S1]. Custom registration disclaimers can be added to webinars and recordings to support GDPR compliance [S2]. When visitors open GoTo's registration page, GoTo processes data on its own site under its own privacy policy, including cookies placed with consent [S3].

## Step 1 — Implement GoTo Webinar

| Configuration area | Fixed behaviour / required action |
|---|---|
| Processing purposes | Unlock additional website features (webinar registration); Receive marketing offers (if registrations feed marketing) |
| Website integration | Link to the GoTo registration page; no script on your site |
| Registration disclaimer | Add a custom disclaimer [S2] |
| Contract | GoTo DPA [S1] |

## Step 2 — Map the configuration in the Consenter Manager

| Consenter Manager field | Value to select | Basis and conditions |
|---|---|---|
| Entry needed | No for a plain link; mention GoTo in the privacy policy | No script on your site |
| Processing purposes | Unlock additional website features | If you embed a GoTo registration via a third-party form (e.g. HubSpot), map that form tool |
| Tracking method | No tracking | Link only |
| Identifier | Direct identifier (on registration) | Registration data |
| Data categories | User-provided data, direct identifier | Registration data |
| Legal role of data recipient | Processor | [S1] |
| Personalisation model | No personalisation | — |
| Maximum storage duration | Per GoTo retention | — |
| Processing location | United States | US enterprise; 18 U.S.C. § 2713 [S4] |
