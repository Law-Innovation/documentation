Typical processing purposes: Unlock additional website features

<Callout type="info" title="Overview">
This guide explains how to implement different privacy configurations for Issuu publications on a website and how to reflect them in the Consenter Manager.

1. Configure the third-party service.
2. Map the selected configuration in the Consenter Manager.
3. Update your privacy policy to reflect the actual implementation.

The configurations are comparative examples, not guarantees of legal compliance. Verify that the guide matches your product edition, implementation, and current provider documentation.
</Callout>

## At a glance

**Scope.** Issuu publications linked from or embedded on the website. Issuu Inc. (Palo Alto, US) is part of Bending Spoons S.p.A. (Italy) [S1][S2]. Sources were checked on 16 November 2026.

**What the service does in this scope.** Embedded Issuu publications set third-party cookies; interacting with embedded publications requires accepting them [S3]. Legal Web describes the data transfer for embeds as to Issuu as joint controller [S1]. Issuu's privacy policy does not cover processing it carries out as a processor, which is governed by its DPA [S2].

**Configurations included.**

| Configuration | Summary |
|---|---|
| Configuration A — Lower risk | Link to the publication on Issuu (or a downloadable PDF); no embed. |
| Configuration B — Higher risk | Embedded Issuu reader loaded after Consenter consent / click-to-load. |

## Step 1 — Configure Issuu

| # | Configuration area | Where to configure it | Configuration A — Lower risk | Configuration B — Higher risk |
|---|---|---|---|---|
| 1 | Processing purposes | Operator decision | — | Unlock additional website features |
| 2 | Integration | Website code | Link | Issuu embed code |
| 3 | Loading | Consenter script blocking / click-to-load | — | After consent |

## Step 2 — Map the configuration in the Consenter Manager

**Processing location.** Issuu Inc. is a US enterprise subject to 18 U.S.C. § 2713 [S4]; list the United States.

| Consenter Manager field | Configuration A — Lower risk | Configuration B — Higher risk |
|---|---|---|
| Entry needed | No | Yes |
| Processing purposes | — | Unlock additional website features |
| Tracking method | No tracking | Third party tracking (crosssession, cross-website) |
| Identifier | No identifier | Device identifiers |
| Data categories | — | Browsing and interaction data, Device characteristics, Device identifiers, IP address |
| Legal role of data recipient | — | Joint Controller |
| Personalisation model | — | No personalisation |
| Maximum storage duration | — | Per Issuu cookie policy |
| Processing location | — | United States; Italy (Bending Spoons) |
