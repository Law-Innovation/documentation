Typical processing purposes: Receive marketing offers, Receive personalised marketing offers

> This guide explains how to reflect Evalanche in the Consenter Manager. SC-Networks does not publish technical details of Evalanche's website tracking, so this guide uses a single fixed-behaviour table.
>
> 1. Implement the service as described below.
> 2. Map the implementation in the Consenter Manager.
> 3. Update your privacy policy to reflect the actual implementation.
>
> The mapping is an example, not a guarantee of legal compliance. Verify it against your implementation and current provider documentation.

## At a glance

**Scope.** Evalanche marketing automation by SC-Networks GmbH, Starnberg, Germany [S1]: forms and, where used, website tracking. Sources were checked on 16 November 2026.

**What the service does in this scope.** SC-Networks states that the use of tracking functionalities is configuration-dependent and must be controlled organisationally [S1]. Evalanche processes data as a processor under a data processing agreement [S2].

> ⚠ **Research gap.** Cookie names, lifetimes and the exact behaviour of Evalanche's website tracking were not found in public documentation. Inspect the implementation in the browser and request the technical documentation from SC-Networks before finalising the mapping.
