# Consenter Documentation

[Consenter](https://www.consenter.eu) is Europe's first officially recognized consent management service, approved by Germany's Federal Commissioner for Data Protection. It gives individuals genuine control over their data while helping website operators achieve GDPR compliance that actually works as a competitive advantage — not just a legal checkbox.

The platform covers three areas: a **Consent Agent** browser extension for individual users, a **Cookie Banner** for website operators, and a **Technology Risk Assessment** tool for technology providers. It is built on over a decade of interdisciplinary research and a participatory design process that keeps users at the center.

This repository holds the documentation for Consenter. It covers setting up the consent banner, configuration guides, and integration guides for third-party tools like Google Analytics, Matomo, Hotjar, and more.

This site uses [Fumadocs](https://fumadocs.dev), a documentation framework built on top of Next.js. Content is written in MDX files stored in the `docs/` directory, with images in `assets/`.
